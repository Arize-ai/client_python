# ProjectType

The kind of LLM project. - `APPLICATION` — A user-facing LLM application project. - `HARNESS` — An agent harness session project. - `EXPERIMENT` — An experiment trace project. 

## Enum

* `APPLICATION` (value: `'APPLICATION'`)

* `HARNESS` (value: `'HARNESS'`)

* `EXPERIMENT` (value: `'EXPERIMENT'`)
