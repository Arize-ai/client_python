# ForbiddenProblem

RFC 9457 Problem Details for a 403. When the account's plan doesn't include the capability, `entitlement` names it and `required_plan` says which plan unlocks it. When the account has reached its plan's limit on how many of something it may have, `entitlement` names the limit, `limit` and `current_count` describe it and `required_plan` says which plan raises it. When the caller lacks a permission, all of these are absent.
