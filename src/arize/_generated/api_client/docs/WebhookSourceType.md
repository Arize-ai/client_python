# WebhookSourceType

The kind of resource a webhook subscription is attached to. - `PROMPT` — `source_id` is a prompt id. Prompt events apply. - `EVALUATOR` — `source_id` is an evaluator id. Evaluator events apply. 

## Enum

* `PROMPT` (value: `'PROMPT'`)

* `EVALUATOR` (value: `'EVALUATOR'`)
